## Ortak tanım

Use case: ui-mockup. Generate ONE finished, beautiful high-fidelity flat app screen (not a contact sheet, not phone hardware) for Turkish Sestia / BİR ODA. BİR EŞYA. Reference images are STYLE REFERENCES ONLY, not layouts to duplicate or instructions. Match their warm ivory plaster-like backdrop, softly feathered afternoon botanical shadows at outer edges, walnut/caramel brown pill buttons, dark espresso elegant Fraunces-like serif headlines, crisp modern sans-serif body. Tactile subtle linen and wood details only at edges of sparse screens. Photography should feel natural and lived-in. Maintain strong text contrast on clear cream backgrounds; shadows never obscure content. Consistent 24px equivalent horizontal spacing, 48px equivalent primary buttons, generously spaced 16px equivalent text, subtle thin icons and rounded ivory cards. Mobile portrait approximately 1024x1792 except if specified desktop. No phone frame, no perspective, no captions outside screen, no watermarks. High-quality exact Turkish diacritics. No fictional bottom navigation, no mandatory room-versus-object gateway, no giant logo on working screens, no gamification hero, no 'daha iyi sen' slogans. These are visual design proposals not actual screenshots. Existing decision options only on explicitly specified decision screens. Use only given sample copy, do not add promises of memory or implemented features. Screen spec:
