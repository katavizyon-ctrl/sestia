# Materials Research Round 1 — Visual Source Inventory (Output 3)

## Read this first

**Images were not viewed in this round.** Each entry is a *candidate visual source*: a page, collection or document that is described (by its publisher or the search index) as containing imagery of the kind listed.

- The "Shows" column is what the source is **expected** to show, not something checked.
- Before any image is preserved or used, it must be opened, checked and its usage terms read.

**Purpose codes:**

| Code | Purpose |
|---|---|
| ID | Identification |
| TX | Surface / texture |
| CD | Condition / aging / damage |
| AP | Application |

**Other columns:**
- **Tech. evidence:** whether the image itself could support a technical claim. Almost always NO — at most, a documented reference image supports *identification*.
- **Preserve?:** Worth keeping locally: YES / NO / LATER (only after the image has been viewed and its licence checked).

Where a material has fewer than 3 candidates, the table says so. Missing visual sources are a finding, not an omission to be padded.

## Observations on visual research (feed the main record)

1. **Authoritative visual sources are collection-level, not image-level.** Examples: CAMEO, BGS, InsideWood, the Wood Database. A permanent visual record would need to point at a specific image *and* at its collection.
2. **The most useful identification views are almost never "beauty shots".** They are:
   - end grain (wood);
   - the cut edge or cross-section (plywood, MDF, leather, porcelain body, laminated glass interlayer);
   - breakage pattern (glass);
   - pores (travertine).
3. **Several pairs of materials are visually ambiguous in normal photos:**
   - acrylic vs polycarbonate;
   - engineered quartz vs marble-look porcelain vs marble;
   - natural vs PE rattan;
   - full-grain vs embossed PU (surface view);
   - tempered vs annealed glass (intact).
4. **Condition/damage imagery from authoritative sources is scarce** for consumer surfaces (etching, MDF swelling, mirror desilvering, PU peeling). What exists is mostly Tier D.
